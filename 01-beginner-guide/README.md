# 보르타 이지스(Vorta Aegis) 초보자·전문가 통합 안내 허브

> **이 문서는 누구를 위한 것인가요?**  
> *"주파수, 위상 상쇄, WASAPI, C#, Git 같은 말을 한 번도 들어본 적 없는 완전 초보자"* 부터  
> *"실제 오디오 신호 처리(DSP) 코드와 검증 수치를 직접 확인하고 싶은 전문가"* 까지  
> **누구나 중간에 막히지 않고 프로젝트의 전체 맥락·해결 과정·실제 사용법을 이해**할 수 있도록 작성된 안내서입니다.

## 문서 작성 원칙

1. **전문용어 병기 원칙**: 낯선 기술 용어(`Hz`, `dBTP`, `WASAPI`, `Decimation`, `SemVer 2.0`, `Git Worktree` 등)를 처음 쓸 때는 **반드시 바로 뒤에 일상 언어로 된 쉬운 풀이**를 함께 적었습니다.
2. **사례별 동일 구조 (`Structured Few-Shot`)**: 7가지 핵심 개선 사례를 모두 **[사용자 증상 → 초보자 원인 진단 → 전문가 해결 설계 → 실측 검증 증거 → 체감 변화]**의 동일한 5단계 틀로 통일해 비교하기 쉽습니다.
3. **실측 근거 기반 원칙 (`MIA Strategic Framework`)**: 추측이나 꾸며낸 숫자 대신, 실제로 빌드·실행해 통과한 파일 크기·테스트 횟수·명령어 결과만 기록했습니다.
