# 04. 전문용어 쉬운 사전 (`ELI10` 용어집)

> **"모르는 것을 모르는 사용자"** 도 문서를 읽다 막히지 않도록, 보르타 프로젝트의 소스코드·보고서·검증 로그에 등장하는 **26가지 핵심 전문용어**를 일상 비유와 실제 역할로 풀어쓴 사전입니다.

---

## 1. 소리 · 음향 신호 처리(`DSP`) 용어

| 전문용어 (영문 원어) | 초보자 눈높이 쉬운 설명 (`ELI10` 비유) | 보르타 앱에서의 실제 역할 |
|---|---|---|
| **Hz (헤르츠, Hertz)** | **1초 동안 공기가 떨리는 횟수.** 심장이 1초에 1번 뛰면 1 Hz, 7번 흔들리면 `7 Hz` 입니다. | 각 프리셋의 기본 주파수(`7.00 Hz`, `40 Hz`, `528 Hz` 등)를 나타내는 단위 |
| **DSP (Digital Signal Processing)** | **컴퓨터 안에서 소리를 요리하는 주방.** 날것의 숫자 데이터에 볼륨 조절, 노이즈 섞기, 찌그러짐 방지를 실시간으로 계산합니다. | `AegisDspEngine.cs`가 담당하는 심장부 오디오 계산 엔진 |
| **NCO (Numerically Controlled Oscillator)** | **오차 없는 전자 메트로놈.** 0.0001초의 어긋남도 없이 정확한 박자로 부드러운 S자 물결(정현파) 각도를 만들어 냅니다. | 64비트 정밀 계산으로 장시간 틀어도 음이 흔들리지 않게 유지 |
| **180° 역위상 상쇄 (Anti-Phase Cancellation)** | **그네를 정반대 타이밍에 밀어 멈추기.** 왼쪽이 위로 갈 때(`+1`) 오른쪽이 아래(`-1`)로 가면 공간의 불필요한 울림이 상쇄됩니다. | `안티방어` 탭의 저주파 진동·공진 완화 프리셋 핵심 원리 |
| **바이노럴 비트 (Binaural Beat)** | **양쪽 귀에 조금 다른 속도 들려주기.** 왼쪽 `200 Hz`, 오른쪽 `240 Hz` 를 들려주면 뇌가 그 차이인 `40 Hz` 리듬을 스스로 느낍니다. | 집중(`14~40 Hz`), 명상(`7.83 Hz`), 수면(`1~4 Hz`) 유도 프리셋 핵심 원리 |
| **반송파 (Carrier Wave)** | **작은 편지(`7 Hz`)를 멀리 나르는 우체부 트럭(`144 Hz`).** 작은 PC 스피커는 7 Hz를 직접 낼 수 없어 144 Hz에 실어서 보냅니다. | `PC 스피커 보정` 모드에서 소형 스피커에서도 체감되도록 보정 |
| **배음 (Harmonics)** | **기타 줄 하나를 튕길 때 같이 울리는 2배·3배 높은 화음들.** 기본 음이 너무 낮을 때 귀가 음정을 인식하도록 돕습니다. | 초저주파가 스피커 한계로 사라지지 않게 돕는 보조 성분 |
| **핑크 / 브라운 노이즈 (Pink / Brown Noise)** | **인공적인 소음을 가려 주는 부드러운 자연의 비·폭포 소리 커튼.** 브라운 노이즈(`1/f²`)는 핑크보다 저음이 더 포근합니다. | `PC Pro` 팩에서 카페 말소리·키보드 소리 차폐(마스킹)에 사용 |
| **FM / AM / RM 변조 (Modulation)** | **소리 물결에 파도타기 변화를 주는 기술.** FM은 음높이를 흔들고, AM은 볼륨 크기를 흔들며, RM은 두 파동을 곱해 귀의 내성을 막습니다. | 장시간 들었을 때 귀가 무뎌지는(청각 내성) 현상 방지 |

## 2. 오디오 품질 · 안전 검증 용어

| 전문용어 (영문 원어) | 초보자 눈높이 쉬운 설명 (`ELI10` 비유) | 보르타 앱에서의 실제 역할 |
|---|---|---|
| **WASAPI (Windows Audio Session API)** | **Windows 소리의 고속 전용차선.** 브라우저나 불필요한 중간 단계를 거치지 않고 사운드카드로 직접 소리를 보냅니다. | Shared-Mode 32-bit Float (`48 kHz`) 저지연 고음질 출력 엔진 |
| **dBFS (Decibels Relative to Full Scale)** | **디지털 음량 천장(`0 dBFS`)을 기준으로 얼마나 아래인지 재는 눈금.** `-9.6 dBFS` 는 천장보다 여유 있게 작다는 뜻입니다. | 앱 화면 우측 텔레메트리 카드의 `실출력 레벨` 표시 |
| **트루피크 (`dBTP`, True-Peak)** | **디지털 점과 점 사이에서 실제로 솟아오르는 아날로그 봉우리.** 숫자 점만 보고 방심하면 스피커에서 튀어 나올 수 있어 `4배` 촘촘히 검사합니다. | 보르타 v3.2는 전 프리셋을 **`-0.50 dBTP` 이하** 천장 안으로 엄격히 제한 |
| **하드 클리핑 (Hard Clipping)** | **천장에 머리를 부딪쳐 파동 꼭대기가 납작하게 잘리는 현상.** 지직거리는 찢어진 잡음과 스피커 손상의 주범입니다. | `v3.2`에서 완전 제거 (`OvershootCount == 0` 검증) |
| **리미터 (Linear Limiter)** | **천장에 닿기 전에 속도를 줄여 주는 지능형 안전 쿠션.** 120% 증폭 시에도 잘리지 않고 부드럽게 한도를 지켜 줍니다. | `100% ~ 120%` 클린 증폭 구현의 핵심 안전장치 |
| **DFT / THD+N** | **소리 성분 돋보기(`DFT`)로 잡음 비율(`THD+N`) 재기.** 순수 음정 외에 찌그러진 잡음이 얼마나 섞였는지 백분율로 잽니다. | `40/200/528/1000 Hz` 에서 **`THD+N < 0.1%`** 실측 통과 |

## 3. 파동 스코프 · Windows UI 용어

| 전문용어 (영문 원어) | 초보자 눈높이 쉬운 설명 (`ELI10` 비유) | 보르타 앱에서의 실제 역할 |
|---|---|---|
| **데시메이션 (Decimation)** | **먼 산을 보기 위해 한 발짝 뒤로 물러서기.** `48,000`번 찍던 사진 중 32장에 1장씩 추려 `1,500 Hz` 로 넓고 천천히 기록합니다. | `7.00 Hz` 초저주파의 매끄러운 S자 물결 3주기를 한 화면에 표시 |
| **히스테리시스 트리거 (Hysteresis Trigger)** | **떨리는 손에 흔들리지 않는 카메라 셔터.** 작은 잡음 문턱을 무시하고 확실한 파동 상승 구간만 잡아 그래프가 멈춘 듯 안정시킵니다. | 오실로스코프 화면이 좌우로 튀지 않고 또렷하게 보이게 함 |
| **WPF & WindowChrome** | **Windows 화면을 벡터처럼 선명하게 그리는 최신 도구(`WPF`)** 와 테두리 없는 세련된 창 크기를 자유롭게 늘리게 해 주는 프레임(`WindowChrome`). | 창 크기 `400×540` ~ 최대화까지 자유 리사이즈 지원 |
| **GridSplitter** | **방 안의 이동식 칸막이.** 마우스로 가운데 줄을 끌어 왼쪽 제어판과 오른쪽 프리셋 카드 넓이를 원하는 대로 조절합니다. | 사용자 맞춤형 자동·수동 2단 레이아웃 저장 (`ConsolePaneWidth`) |
| **이벤트 전파 / `e.Handled = true`** | **부모가 애들 장난감 뺏기 전에 *"이건 내 거야!"* 하고 먼저 외치기.** 버튼이 클릭을 먼저 처리해 배경 드래그(`DragMove`)가 훔쳐 가지 못하게 막습니다. | 미니바 **`[전체]`** 버튼 무반응 버그의 근본 해결 키 |

## 4. 제품화 · 저장소 관리 용어

| 전문용어 (영문 원어) | 초보자 눈높이 쉬운 설명 (`ELI10` 비유) | 보르타 앱에서의 실제 역할 |
|---|---|---|
| **SemVer 2.0 (Semantic Versioning)** | **`큰변화.기능추가.버그수정` (예: `3.2.0`)으로 버전을 매기는 세계 표준.** 뒷꼬리 숫자가 아무리 길어도 정확히 대소를 비교해야 합니다. | `UpdateChecker.cs` 의 온라인 업데이트 판별 기준 (`CompareAsciiUnsignedInt`) |
| **Schema v1 (JSON 확장 규격)** | **추가 프리셋 팩이 꼭 지켜야 할 표준 도시락 통 규격.** 규격이 맞으면 앱을 다시 빌드하지 않고도 새 사운드 팩을 바로 열 수 있습니다. | 코어 `48종` + `PC Pro` `16종` = `64종` 및 사용자 외부 팩 핫로드 |
| **PE VersionInfo** | **Windows 실행 파일(`.exe`) 우클릭 → [자세히] 탭에 새겨지는 공식 신분증.** 제품명, 버전 `3.2.0.0`, 저작권자 이름이 적힙니다. | `AssemblyInfo.cs` 를 통해 상용 품질 바이너리 메타데이터 각인 |
| **EULA / CROS / KIPRIS / MSIX** | **앱 사용 계약서(`EULA`), 한국 저작권 등록(`CROS`), 상표 등록(`KIPRIS`), Microsoft 공식 서명 패키지(`MSIX`).** | `LICENSE` 작성 및 `04-docs/02-commercial-licensing/` 정식 인증 로드맵 |
| **Git Worktree (워크트리)** | **원본 작업실을 어지럽히지 않고 옆방에 깨끗한 사본 작업대를 펴는 Git 기능.** 안전하게 저장소를 정리하고 푸시하는 데 쓰입니다. | 로컬 작업 유지한 채 GitHub 6-폴더 재구성 및 푸시 완수 |
| **SHA-256 해시 대조** | **파일 내용마다 붙는 64자리 고유 지문.** 저장소 정리 전후로 모든 고유 파일 지문을 비교해 **자료 유실 0건**을 증명합니다. | `sync_vorta_github.py` 의 `ZERO_LOSS_GATE` 자동 검증 |
