## 2. 안드로이드 프레임워크 역설계 (`services_0.dex` / `services.dex`) 및 안전볼륨 동등성 설계

### 2.1 S6 (`API 24`, `services_0.dex`) · S7 (`API 26`, `services.dex`) `AudioService` 핵심 분석
1. **안전볼륨 상수 및 20시간 누적 타이머**:
   - 두 기종 모두 프레임워크 내부 `mSafeMediaVolumeIndex=90` 및 누적 재생 `20시간`(`0x044aa200` ms) 경과 후 재잠금(`SAFE_MEDIA_VOLUME_ACTIVE = 3`) 로직을 보유합니다.
   - 유선 오디오(`3.5mm AUX`) 재연결 시 `onSetWiredDeviceConnectionState` 내부 9단계 클램프 및 상태 재평가 루틴이 실행되며, 유선 볼륨을 강제 하향(약 85% / 안전 인덱스 상한)합니다.
2. **OS 버전별 권한 차이 (`mControllerService` vs `STATUS_BAR_SERVICE`)**:
   - **S6 (API 24)**: `AudioService`의 `mControllerService` 경로를 통해 화면이 꺼진 상태(`mWakefulness=Asleep`)에서도 `Direct-Binder` `disableSafeMediaVolume()` 호출이 동작함을 실기에서 확인(`state 3->2`, `vol_ctrl=null`, `FAILSAFE_30S_CLAMP`).
   - **S7 (API 26)**: `AudioService.enforceVolumeController`가 `android.permission.STATUS_BAR_SERVICE` 권한을 요구하도록 강화되어, 시스템 팝업 기반 해제 경로(잠금화면 관통 다이얼로그 해제 + `VortaAccessibilityService`)와 이벤트 기반 보완이 필수입니다.
3. **`VortaVolumeGuard.java` 3대 동등성 보강 (A30 수준 자유 볼륨 목표)**:
   - `DIALOG_RETRY_WINDOW_MS = 30s` 내 반복 복원 및 유선 분리(unplug) 300ms 후 `enforceSystemFlags + applyWiredIndexes` 적용.
   - `STREAM_DEVICES_CHANGED_ACTION` + `ACTION_AUDIO_BECOMING_NOISY` 브로드캐스트 수신으로 3.5mm/배선 변화 즉시 대응.
   - 잠금화면 복귀 시 쿨다운(`4000ms`)을 상회하는 `+5000ms` 재시도 예약으로 재클램프 누락 차단.
4. **백그라운드 프로세스 생존성 (`MARs` / Doze)**:
   - S6 실측 `sys.config.mars_version=2.00` 포함 S6/S7의 삼성 `MARs`(`com.samsung.android.lool`) 강제 절전을 회피하기 위해 `appops RUN_IN_BACKGROUND allow` 및 Doze 화이트리스트 구성, 전경 서비스(`VORTA v5.1`) 유지가 결합됩니다.

## 3. 수동 측면 전원 버튼 외 화면 자동 꺼짐 방지 조사 (`PowerManagerService`)

### 3.1 `PowerManagerService.getScreenOffTimeoutLocked(int)` 역설계 결과
바이트코드 분석 결과 Android/Samsung `PowerManagerService.getScreenOffTimeoutLocked(int)`는 다음 우선순위로 실제 화면 꺼짐 시간을 결정합니다:
1. 기본 설정값 `mScreenOffTimeoutSetting`과 기기 관리자 상한 `mMaximumScreenOffTimeoutFromDeviceAdmin` 중 최솟값 선택 (`min(...)`).
2. 창 관리자 재정의 `mUserActivityTimeoutOverrideFromWindowManager` 반영.
3. 시스템 하한 `mMinimumScreenOffTimeoutConfig` 이상으로 보정 (`max(...)`).
4. 삼성 프레임워크 분기(`USE_DEVICE_LOCK_TIME` / `mSecuredLockTimeoutSetting`, 로그 문자열 `"getScreenOffTimeoutLocked return mSecuredLockTimeoutSetting"`): 잠금화면(`Keyguard`)이 표시된 상태에서는 별도의 짧은 잠금화면 타임아웃이 적용되어 화면이 조기 소등될 수 있음.
- **물리적 측면 전원 버튼 동작**: 사용자가 측면 전원 키를 누르면 위 타임아웃과 무관하게 OS가 즉시 `goToSleep()`을 실행합니다.
