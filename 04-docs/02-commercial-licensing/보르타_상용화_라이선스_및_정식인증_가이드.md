- **효과**: 한국 법원·스토어 분쟁 시 **창작일·저작권자 추정력(법적 1차 증거)** 확보. 도용·무단 복제 대응 시 가장 가성비 높은 공식 등록입니다.

### STEP 2. 특허청 **KIPRIS** 선행조사 → **특허로** 상표권 출원 (브랜드 독점)
- **사전 검색**: 특허정보넷 `https://www.kipris.or.kr` 에서 `"보르타"`, `"Vorta"`, `"Vorta Aegis"` 유사 상표 검색

- **효과**: 상표 등록 완료 시(출원 후 통상 10~14개월, 우선심사 시 단축) `®` 표기 및 오픈마켓·앱스토어 사칭 앱 즉시 신고·차단 가능.

### STEP 3. Windows 코드 서명 (SmartScreen 경고 해소 & 신뢰 확보)
현재 `VortaAegisPC.exe`는 로컬 빌드(미서명) 상태이므로, 타인 PC에 배포하면 Windows Defender SmartScreen 파란 경고창이 뜰 수 있습니다. 아래 **2가지 정식 경로** 중 하나를 선택하세요.

| 경로 | 대상 · 적합 시나리오 | 핵심 절차 및 특징 |
|---|---|---|
| **경로 A: Microsoft Store 배포 (개인/1인 개발자 최우선 추천)** | 개인 개발자 · 초기 상용화 | ① Microsoft Partner Center 개발자 계정 등록 → ② `VortaAegisPC.exe` + `packs/` + `web/`를 **MSIX 패키지**로 패키징 → ③ Microsoft Store 심사 통과 시 **Microsoft가 자체 인증서로 자동 재서명**. 별도 연 수십만 원대 하드웨어 인증서 비용 없이 SmartScreen 문제 즉시 해결 및 결제/자동 업데이트까지 일괄 제공 |
| **경로 B: 자체 웹 판매용 코드 서명 인증서 + SmartScreen 등록** | 자사몰·Gumroad·Lemon Squeezy 직접 `.exe`/`.msi` 판매 | ① CA(Certum, DigiCert, Sectigo 등)에서 **OV 또는 EV HSM 코드 서명 인증서** 발급 (최근 CA 규정상 개인키 파일 `.pfx` 금지, USB 하드웨어 토큰 또는 클라우드 HSM 필수. ※ Azure Artifact Signing은 현재 주로 미국/캐나다/EU/영국 사업자 대상이므로 한국 개인/법인은 **Certum Open Source / OV Cloud Signing** 또는 **글로벌 HSM 토큰 인증서**가 현실적) → ② `signtool.exe sign /fd SHA256 /tr http://timestamp.digicert.com` 로 서명+타임스탬프 각인 → ③ 배포 파일 해시를 Microsoft Security Intelligence (`microsoft.com/en-us/wdsi/filesubmission`) 에 제출해 초기 SmartScreen 평판 확보 |

### STEP 4. 유료 결제 · 정품 라이선스 키 인증 체계 구축
1. **글로벌 1인/소규모 소프트웨어 결제(MoR 추천)**:
   - **Lemon Squeezy** 또는 **Paddle**: 전 세계 부가세(VAT) 신고·영수증·**자동 라이선스 키 발급·해지/기기 활성화 수 제한**을 플랫폼이 대행(Merchant of Record)하므로 초기 법인/PG 연동 부담을 크게 줄일 수 있습니다.
   - **국내 직접 결제**: 개인/법인 사업자등록 + 통신판매업 신고 + PG사(토스페이먼츠·포트원 등) 연동.
2. **앱 내부 인증 설계(현 v3.2 확장 용이 구조)**:
   - 오프라인 보르타 철학에 맞춰, 향후 **Ed25519 공개키 서명 기반 오프라인 라이선스 파일/키**를 권장합니다(`VortaAegisPC.exe` 내부에 공개키만 내장, 결제 서버가 비밀키로 `licenseKey + packId + seatCount` 서명 발급 → 인터넷 없는 PC에서도 1ms 내 오프라인 정품 인증 가능).
   - 유료 **Pro 확장 팩(`packs/*.vortapack` 또는 서명된 JSON)** 만 잠금/해제하고 기본 체험판(코어 또는 일부 프리셋)을 두는 **Freemium 모델**이 전환율이 높습니다.

### STEP 5. 스토어·법규 비의료 컴플라이언스 유지
- 제품 설명, 앱 내 프리셋 문구, 확장 팩 JSON에 **"치료", "질병 예방", "치유", "의학적 진단"** 표현을 절대 넣지 않고, **"집중 보조", "휴식·이완", "환경음 마스킹", "일반 웰니스"** 표현만 유지합니다(v3.2 `vorta_pc_pro_pack_v1.json` 전수 준수 완료).
